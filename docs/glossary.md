# Glossary

[Start](../README.md)

| Term | Plain-language meaning |
| --- | --- |
| ARP | Address Resolution Protocol: finds a local-link MAC for an IPv4 next hop |
| MAC | Link-layer address associated with a network interface; used for delivery on the current link |
| IPv4 | Network-layer addressing and routing protocol using 32-bit addresses |
| Ethernet | Link-layer framing technology used to deliver frames among interfaces on a local network |
| Gateway | Next-hop router used when a destination is outside the local subnet |
| Subnet | A range of IP addresses treated as one logical network for routing decisions |
| Router | Device that forwards IP packets between networks, rebuilding link-layer frames per hop |
| Switch | Device that forwards frames within a Layer 2 network |
| MITM | Man in the middle: a path where a third system can observe or relay traffic between endpoints |
| ARP poisoning | Supplying a misleading IPv4-to-MAC claim that changes neighbor state |
| ARP cache | A host's stored local IPv4-to-MAC mappings, also called neighbor entries |
| NAT | Network Address Translation: rewrites address information at a network boundary |
| ICMP | Internet Control Message Protocol; includes echo request and reply used by ping |
| TCP | Connection-oriented transport protocol with ordered byte delivery |
| UDP | Datagram transport protocol without TCP's connection handshake |
