# Security and abuse reports

Please report vulnerabilities, unsafe instructions, exposed data, or abuse concerns through this repository's GitHub **Security** tab using a private vulnerability report if that feature is enabled. If it is unavailable, open a minimal public issue that describes the concern without exploit details or sensitive material and ask the maintainers for a private channel. No contact address is asserted here.

Do not post credentials, API keys, private packet payloads, session data, or personal network details in issues, commits, or screenshots. Sanitize evidence before sharing. Maintainers should review reports privately, assess impact, and coordinate fixes before publishing technical details.
